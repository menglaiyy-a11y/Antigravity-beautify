# Antigravity 极简纯净透底美化套件 (Apple Design Language)

基于 Apple 官网设计语言与 Electron 渲染穿透技术构建的 Google Antigravity 高阶美化与控制台套件。

---

## 🌟 核心特性

1. **动态表情包入口 (锁暝捏捏像素墨镜反光)**
   - 控制台悬浮按钮由原文字药丸升级为专属动态表情包（鸣潮锁暝捏捏像素墨镜反光动图）；
   - 按钮尺寸适中（52px × 52px，圆角 14px），带有 Apple 标志性极简晶莹微透毛玻璃托底；
   - 支持在屏幕边缘任意拖拽停放，记忆停靠位置，点击即可展开/收起控制台面板，保留全局快捷键 `⌥T`（`Alt+T`）。

2. **质感双模一键切换：晶莹磨砂 vs 柔雾类纸膜**
   - **晶莹磨砂 (Frosted Glass)**：Apple 经典高通透毛玻璃与高光微边缘质感，通透纯粹；
   - **柔雾类纸膜 (Matte Paper Texture)**：模拟类纸护眼屏，降低眩光高反光，注入全屏 SVG 微噪点漫反射滤镜，柔和素描微漫边，极大减轻长时间编程与阅读的视觉疲劳。

3. **MP4 动态视频素材导入与全屏硬件加速播放**
   - 本地素材模块全面升级，支持直接点击选取或拖拽 `.mp4` 动态视频文件；
   - 底层挂载全屏硬件加速 `<video autoplay loop muted playsinline>` 循环播放；
   - 集成浏览器原生 IndexedDB 异步大容量存取，应用重启后自动无损恢复视频壁纸，并与常规图片素材平滑双模切换。

4. **深度穿透与晶莹毛玻璃**
   - **主对话流全穿透与滚动视口防遮挡**：消灭多层 wrapper 背景阻断，主对话卡片采用 26px/30px 优雅呼吸内边距；主滚动容器配置 `padding-top: 56px` 与 `scroll-padding-top: 56px` 安全留白；彻底取消 `sticky top-0` 强行顶格粘滞并消除 `mask-image` 渐变雾化遮挡，无论向上或向下滑动，对话卡片自然平滑流动，第一行字始终处于安全视口内，绝不再被面包屑顶栏遮挡；
   - **左侧栏（Sidebar）重构为 Apple 极简通透风格**：精准靶向真实左栏容器 `div.bg-sidebar`，彻底清除所有子条目生硬斑驳的深黑、深灰与暗土灰补丁底色；将「+ 新建对话」按键打造为晶莹典雅的 Apple 纯白微透毛玻璃胶囊（`rgba(255, 255, 255, 0.09)`，9px 圆角，质感内发光）；文件夹条目（6, 2, 5, 1, 3, 4）透明化无死黑；会话列表项统一为柔和微透卡片；侧边栏全部文字与 SVG 图标统一为纯净亮白 `#ffffff`，消除暗灰字，视觉通透协调；
   - **右上角窗口控制按钮全链路透明**：在 Electron 主进程底层 `utils.js` 创建窗口时将 `titleBarOverlay.color` 默认值设置为 `'#00000000'`，并在 `dom-ready` 与 `did-finish-load` 绑定生命周期透明保底；在 `preload.js` 启动第一毫秒通过原生 IPC 主动上报全透明；配合渲染层每 2.5 秒保底刷新与 focus/resize 监听，实现 4 重保险，客户端冷启动或重启后永远维持 100% 晶莹磨砂质感；
   - **顶框高通透统一性**：消除原生顶栏死黑遮挡，调高透明度使天空壁纸自然穿透，实现全局通透一致性；
   - **聊天输入框低透明度磨砂**：消灭内部死黑遮挡，呈现真正轻薄通透的 Apple 磨砂质感；
   - **加号二级菜单与指令菜单深磨砂**：为点击加号展开的上下文二级菜单、输入 `/` 或 `@` 的补全菜单赋予高遮蔽深磨砂玻璃与高斯模糊，彻底消除底层对话文字重叠干扰，选项与说明纯白高对比度呈现；
   - **设置弹窗透底**：设置弹窗底层壁纸通透呈现，彻底消除死黑死灰，设置项保留微高光磨砂边缘；
   - **编辑器与终端护眼保护**：右侧代码与终端维持 $\ge 75\%$ 基础对比度保护，确保文字清晰易读。

5. **精简调节架构**
   - **全局共享联动（默认）**：仅需调节「全局视窗透明度」与「全局毛玻璃高斯模糊」两个极细圆点滑块，全界面同步联动生效；
   - **独立分栏微调（可选）**：通过右上角微型分段器切换，仅保留「左栏（侧边栏）」、「中栏（对话与设置）」、「右栏（审阅与终端）」三大分区。

6. **Apple 官网纯净风格控制台（纯文字全白字规范）**
   - **彻底去除一切杂乱图标与表情**：移除多余 emoji、移除所有箭头符号与小色块，控制台界面内部仅保留纯净文字；
   - **所有文字统一纯白**：无论是标题、Tab 选项、调节项说明、实时数值、RGB 标签还是按钮文字，全界面统一为高对比度纯白 `#ffffff`。

7. **广色域调色盘与 RGB 精密微调**
   - 点击「广色域色盘」流畅推入二级放大页面；
   - 大尺寸 2D 连续色相/饱和度 Canvas 光谱矩阵与白色指示游标；
   - 色彩亮度（Lightness）独立滑块；
   - **RGB 精准数值微调卡片**：集成 R、G、B 三独立通道数值微调滑块，纯白标签与数值显示，具备严格防 NaN 兜底保护，支持 0~255 精确控制与 Hex 色号联动显示。

## 🚀 使用指南

### 1. 运行中实时热注入（免重启即刻生效）
在终端中执行：
```powershell
powershell -ExecutionPolicy Bypass -File "D:\Antigravity\6\apply_visual_panel_live.ps1"
```

### 2. 系统级固化（重启后依然自动生效）
在终端中执行：
```powershell
powershell -ExecutionPolicy Bypass -File "D:\Antigravity\6\persist_theme.ps1"
```
或者在展开的控制台面板中点击底部的 **「固化配置」** 按钮。

### 3. 一键还原官方纯净状态
若需复原系统默认外观，在终端中执行：
```powershell
powershell -ExecutionPolicy Bypass -File "D:\Antigravity\6\restore_default_theme.ps1"
```

## ⌨️ 快捷操作与交互

- **打开/收起控制台**：按键盘 `Alt + T`，或点击右下角锁暝像素墨镜动态表情包；
- **拖动表情包按钮**：按住表情包即可在屏幕任意边缘自由拖拽停放；
- **切换质感风格**：在控制台中点击「晶莹磨砂」或「柔雾类纸膜」；
- **导入 MP4 / 图片素材**：将本地任意 MP4 视频或图片（JPG/PNG/WebP）拖入虚线卡片，或点击选取文件，即刻全屏循环播放；
- **调节全界面通透度**：滑动「全局视窗透明度」即可实时感受光线穿透效果。
